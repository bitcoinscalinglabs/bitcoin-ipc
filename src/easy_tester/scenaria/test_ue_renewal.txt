# A validator cannot renew its key with a second join-ue in the block of the cutoff that
# drops its collateral: the join is processed while it is still a member, and a key joins a
# subnet once.
# Run with testers/db-ue.txt or testers/monitor-ue.txt.
# A collateral with timeout T seats its validator in every configuration computed with a
# boundary below T: C_e, computed at the cutoff H_{e-1} = H_0 + (e-1)K, needs T > H_0 + (e+2)K.
# Epochs are K = 10 Bitcoin blocks here. H_0 is the first Bitcoin block in which the join collateral
# of every member of C_gen is slashable: the Bitcoin block of the first checkpoint, whose batch
# transfer carries the slash pre-signatures. Until the next checkpoint, the rotation checkpoint of
# epoch 1, the current configuration is C_gen.
# Rule 2.6: before activation a timeout is in epochs 4 to 1003 from the join's block (at block
# 110, T > 140); after it, in epochs e+4 to e+1003 from H_0.
# `block N` means what follows goes into block N; a cutoff at block H is visible at `block H+1`.

setup

validator1
validator2
validator3
validator4
validator5

subnet1
whitelist validator1 validator2 validator3 validator4
min 4

scenario

block 105
create subnet1

block 110
join-ue subnet1 validator1 100_000 400
join-ue subnet1 validator2 100_000 400
join-ue subnet1 validator3 100_000 400
join-ue subnet1 validator4 100_000 400

block 112
read validators subnet1
expect result.count = 4
deposit subnet1 validator1 500_000_000
presign subnet1 validator1 by validator1 validator2 validator3
presign subnet1 validator2 by validator1 validator2 validator3
presign subnet1 validator3 by validator1 validator2 validator3
presign subnet1 validator4 by validator1 validator2 validator3

# the first checkpoint: H_0 = 114
block 114
checkpoint subnet1

block 116
read subnet_state subnet1
expect result.h_0 = 114
join-ue subnet1 validator5 100_000 160

block 117
read ue_collaterals subnet1
expect result.count = 5
presign subnet1 validator5 by validator1 validator2 validator3

block 118
checkpoint subnet1

# the cutoff at 124 seats validator5 (boundary 154 < 160)
block 125
read validators subnet1
expect result.count = 5
expect result.waiting = true

# block 134 is the cutoff that drops validator5 (boundary 164): its new join-ue in that block
# is refused, it is still a member
block 134
join-ue subnet1 validator5 100_000 400

block 135
read validators subnet1
expect result.count = 4
expect result.names = validator1,validator2,validator3,validator4
read ue_collaterals subnet1
expect result.validator5.count = 1
expect result.validator5.timeout = 160
read withdrawals subnet1
expect result.count = 1
expect result.validator5 = 100_000
